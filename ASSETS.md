# Assets

Third-party art, audio and content assets actually used in the project, with licences. Code packages (Meta XR SDK, URP, OpenXR, etc.) are listed in the README's tech list instead, not here.

## Third-party assets: none

v1.0 uses no third-party models, textures, icons, fonts or sounds.

| What | Source |
|---|---|
| Furniture (bed, sofa, table, chair, wardrobe) | Built in this project from Unity primitive cubes, sized to the catalog (`Assets/Project/Prefabs/Furniture`) |
| Furniture, ghost, highlight and room-overlay materials | Made in this project with URP shaders (`Assets/Project/Materials`) |
| UI text | Unity's built-in `LegacyRuntime` font |
| UI panels | Plain uGUI images in solid colours; no sprites or icons |
| Controller models and ray visuals | Ship inside the Meta Interaction SDK package |
| Sample rooms (Editor fallback when no device room is available) | Ship inside the Meta MR Utility Kit package |
